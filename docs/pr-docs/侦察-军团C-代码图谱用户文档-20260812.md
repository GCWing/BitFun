### B2. 功能用户可见行为（非实现细节）

1. **AI Agent 会话**：用户发送消息后看到流式文本/工具事件/token 消耗；可取消当前回合、压缩会话、恢复已删会话、分支会话（fork）、查看血缘（lineage）。命令实证：start_dialog_turn/cancel_dialog_turn/compact_session/restore_session/fork_session/get_session_lineage（agentic_api.rs + session_api.rs）。
