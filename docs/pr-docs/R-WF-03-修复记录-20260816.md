## 五、沉淀建议（S-33 四要素）

- **现象**：连续分段 Read 同一大文件被 R-MR-11 工具拦截（3-4 次后拒绝执行）。
- **根因**：大文件（2651+ 行）逐段读取触发碎片化读取检测。
- **绕过方式**：Grep 定位函数行号 → 大段读取（≥300 行）或 PowerShell 提取区段。
- **教训**：大文件读取必须整段或先 Grep 精确定位，禁小步分段读。
