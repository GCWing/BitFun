## 1. 方案（契约唯一权威源）

| # | 方案项 | 落地位置 |
|---|--------|----------|
| 1 | 前端 Session 加 orphaned 标记（后端 metadata 带出） | `flow-chat.ts` Session + `session-history.ts` SessionMetadata 新增 `orphaned`/`orphanKind`；后端 `SessionMetadata` 结构新增 `orphaned: bool` + `orphan_kind: Option<String>` |
| 2 | 树构建 orphan 独立分组（「孤立会话」折叠区） | `SessionsSection.tsx` 树构建 useMemo 拆分 `orphanedSessions`，独立折叠区渲染 |
| 3 | OrphanKind 透传（DanglingChild / DetachedChild） | `page.rs` 分页构建时计算标记（relationship 父缺失→DanglingChild；creator marker 父缺失→DetachedChild）；前端 `normalizeOrphanKind` 透传 |
| 4 | pending-parent 标记（分页懒加载缓解） | 孤儿仍计入 top-level 计数、不影响分页 cursor；前端主列表 walk 跳过孤儿避免重复渲染 |

范围：纯前端 + 契约层小改（后端 metadata 已含关系数据，仅 page 构建时计算标记，不新增持久化字段权威值）。
