# 致每一位支持 OpenBitFun 的朋友

OpenBitFun 1.0.0，全新發佈。

感謝每一顆 Star、每一次回饋與貢獻，陪 OpenBitFun 走到今天。

從 Rust Agent Runtime、Agent Harness 到 GUI，我們反覆打磨，
始終為了一個願望：讓更多人把一直想做的事做出來。

1.0.0 帶來四種 Agent Harness，每一種都能獨當一面，你可以根據手頭的事，選擇最合適的那一種。
從電腦到手機、手錶和瀏覽器，再到未來的眼鏡，我們想讓 OpenBitFun 離你的生活更近一點。
當你想做些什麼的時候，它就在手邊，陪你把一個念頭，慢慢變成看得見的成果。

我們會繼續奉行開源精神，把它做得更可靠、更好用。未來的 OpenBitFun，
也期待在更多人的手裡，成為今天還想不到的模樣。

**用它創造，也一起創造它。**
