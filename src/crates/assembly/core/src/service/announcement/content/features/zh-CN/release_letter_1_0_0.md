# 致每一位支持 OpenBitFun 的朋友

OpenBitFun 1.0.0，全新发布。

感谢每一颗 Star、每一次反馈与贡献，陪 OpenBitFun 走到今天。

从 Rust Agent Runtime、Agent Harness 到 GUI，我们反复打磨，
始终为了一个愿望：让更多人把一直想做的事做出来。

1.0.0 带来四种 Agent Harness，每一种都能独当一面，你可以根据手头的事，选择最合适的那一种。
从电脑到手机、手表和浏览器，再到未来的眼镜，我们想让 OpenBitFun 离你的生活更近一点。
当你想做些什么的时候，它就在手边，陪你把一个念头，慢慢变成看得见的成果。

我们会继续奉行开源精神，把它做得更可靠、更好用。未来的 OpenBitFun，
也期待在更多人的手里，成为今天还想不到的模样。

**用它创造，也一起创造它。**
